# 스킬 채택의 세 게이트 (발췌)

| 게이트 | 기준 | 조작적 정의 |
|---|---|---|
| G1 정확한 트리거 | 켜져야 할 때만 켜진다 | should-fire / should-not-fire 쿼리, train/test 분리. 과잉 트리거는 미발동과 같은 실패 |
| G2 확연한 품질 향상 | 스킬 유/무 비교에서 확연히 낫다 | 이득과 회귀를 쌍으로 보고. 기준선 vs 기준선 반복으로 뒤집힘 노이즈 바닥을 먼저 측정. 통과 = 회귀 ≤ 노이즈 바닥 그리고 순이득이 반복 실행에서 일관 |
| G3 과하지 않은 토큰 | 상시 로드 + 실행 비용이 이득에 비해 과하지 않다 | description·본문 크기, 실행 토큰 |

eval 규칙: 케이스당 3회 이상, mean±stddev. 모델 버전·CLI 버전·날짜를 기록. 증거(실행 명령·출력) 필수.
