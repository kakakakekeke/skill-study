Runs the project's tests, type check, and lint fresh after the last edit and reads the exit code before a code change is reported as done, via a deterministic preflight script (changed-file test selection, ruff/mypy, short JSON). Use before reporting any code change as done in a repo with a test runner or linters, even a small rename, and when the user asks if a change is ready, whether anything else broke, or to make sure CI passes. Not for summarizing a failing log, measuring a flaky test, or explaining tests.
