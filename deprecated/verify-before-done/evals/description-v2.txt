Carries out a code change in a repo with tests, a type checker, or a linter and finishes it with a fresh run of tests, type check, and lint and a read of the exit code, via a deterministic preflight script (changed-file test selection, ruff/mypy, short JSON). Use for any edit task in such a repo (add a flag, rename, refactor, fix types, bump a dependency), and when the user asks if a change is ready, what else broke, or to make sure CI passes. Not for summarizing a failing log, measuring a flaky test, or explaining tests.
